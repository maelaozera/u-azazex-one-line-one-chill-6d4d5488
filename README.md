One Line, One Chill — a single sentence of horror, under 200 characters, built to frighten a reader in one breath. The entry is a concrete, specific dread: a found obituary, a date that cannot be, and handwriting the narrator does not recognise as their own. No gore, no mirror, no doll, no basement — the scare is earned by what the line withholds.

## Run it

```sh
node main.ts
```

Running `node main.ts` writes the entry line to `/output/entry.txt`.
